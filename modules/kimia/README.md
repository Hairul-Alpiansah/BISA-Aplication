# KimiaLab — Kimia SMA Interaktif

Aplikasi web statis untuk materi Kimia SMA kelas X, XI, dan XII.

## Isi
- 15 bab (5 bab untuk setiap kelas)
- Navigasi kelas dan bab
- Pencarian materi
- Ringkasan konsep dan rumus
- Visual interaktif berbasis SVG/CSS/JavaScript
- Simulasi atom, VSEPR, stoikiometri, pengenceran, termokimia, laju reaksi, kesetimbangan, pH, koloid, sifat koligatif, sel volta, tren periodik, hidrokarbon, dan polimer
- Kuis 3 soal per bab
- Progres belajar tersimpan otomatis dengan localStorage
- Mode terang/gelap
- Responsive untuk desktop dan ponsel

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser modern.
3. Tidak memerlukan server atau internet.

## Struktur
- `index.html` — struktur halaman
- `styles.css` — desain dan responsivitas
- `script.js` — data materi, simulasi, kuis, progres
