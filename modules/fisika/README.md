# Fisika SMA Interaktif

Aplikasi web statis untuk belajar Fisika SMA kelas X, XI, dan XII.

## Fitur
- 15 bab: 5 bab per kelas.
- Ringkasan materi dan rumus.
- Simulasi/gambar interaktif untuk setiap bab.
- Kuis pemahaman.
- Pencarian materi.
- Progres belajar tersimpan dengan localStorage.
- Mode terang/gelap.
- Responsif untuk desktop dan mobile.
- Tidak membutuhkan library eksternal atau internet.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser.
3. Untuk pengalaman terbaik, Anda juga dapat menjalankan folder melalui Live Server di VS Code.

## Struktur
- `index.html` — struktur halaman.
- `style.css` — desain dan responsivitas.
- `app.js` — data materi, navigasi, progres, kuis, dan 15 simulasi interaktif.
